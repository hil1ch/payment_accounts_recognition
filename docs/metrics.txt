Оцениваются только пары JSON файлов.
сравниваются эталонный JSON и результирующий JSON.

Метрики
1) Процент валидных результирующих JSON
2) Recall для ключей
3) F1 для ключей (с завышенным коэффициентом для recall)
4) Accuracy для значений полей (Проверка, какой процент ключей полностью совпал)
5) Отдельные метрики Recall, Precision, Accuracy для таблиц со списком товаров и услуг
6) Tree distance для структуры JSON.
7) Относительное время генерации ответа (сравнение различных пайплайнов на одном и том же оборудовании)
