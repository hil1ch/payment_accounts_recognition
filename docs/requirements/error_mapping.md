# Коды ошибок и тексты для Telegram-бота

| HTTP | Код ошибки (JSON) | Текст, который бот показывает пользователю |
|------|-------------------|-------------------------------------------|
| `400`  | `VALIDATION_ERROR`  | ❌ Неверный формат запроса. Убедитесь, что вы отправили PDF-файл. |
| `413`  | `PAYLOAD_TOO_LARGE` | ❌ Файл больше 10 МБ. Сожмите или разделите документ. |
| `415`  | `UNSUPPORTED_MEDIA` | ❌ Принимаются только PDF-файлы. |
| `429`  | `TOO_MANY_REQUESTS` | ❌ Слишком много запросов. Подождите 1 мин и повторите. |
| `404`  | `NOT_FOUND`         | ❌ Результат устарел или не существует. Начните заново. |
| `408`  | `REQUEST_TIMEOUT`   | ❌ Превышено времени ожидании ответа от ML сервиса |
| `500`  | `INTERNAL_ERROR`    | ❌ Ошибка сервера. Мы уже разбираемся, попробуйте позже. |
| `502`  | `ML_SERVICE_ERROR`  | ❌ Сервис распознавания временно недоступен. Попробуйте позже. |

**Спец-фраза для любой `5xx` (если бот не может распарсить код):**  
«❌ Техническая ошибка сервера. Попробуйте через несколько минут.»
